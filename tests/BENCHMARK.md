# Benchmark

Generated by `node tests/bench.js --write` — engine 4.0.0, 2026-10-24.

The posts below were written to cover the layouts and edge cases in the brief, alongside the engine. They are a
regression baseline, not a sample of real posts: a layout that isn't here can still trip it up. Add any post that
does to `tests/fixtures/corpus.js` and it is checked from then on.
